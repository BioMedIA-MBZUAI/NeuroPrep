## Citing NeuroPrep

If NeuroPrep contributes to a publication, presentation or other output, please cite it.
The citation metadata is in
[`CITATION.cff`](https://github.com/BioMedIA-MBZUAI/NeuroPrep/blob/main/CITATION.cff);
GitHub shows it as **Cite this repository**.

```bibtex
@software{hassan_neuroprep_2026,
  author  = {Hassan, Salma},
  title   = {{NeuroPrep: resource-aware agentic study compilation for multimodal neuroimaging}},
  version = {0.5.0},
  year    = {2026},
  url     = {https://github.com/BioMedIA-MBZUAI/NeuroPrep},
  license = {PolyForm-Noncommercial-1.0.0}
}
```
