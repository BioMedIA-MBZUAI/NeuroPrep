# Command line

Every command is a subcommand of `neuroprep-agentic`. This page is generated from the
installed parser when the documentation is built, so it always matches the code.
Run `neuroprep-agentic <command> --help` for the same text in a terminal.

Paths must be under your home directory, `NEUROPREP_HOME` or a root listed in
`NEUROPREP_ALLOWED_ROOTS` ([Configuring a host](configuration.md#allowed-roots)).
